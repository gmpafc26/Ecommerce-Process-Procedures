📦 Managing Products in BigCommerce

How to find, edit and manage product listings. Covers the product list, editing basic info, categories, description and images.

📍 How to get to products
BigCommerce Admin → Products → View
The product list — click any product name to open the editor.
1
Find the product
Search by name in the product list. Click the product name (blue link) to open the editor.
Click any product name to open it. ENABLED = visible on storefront.
💡 The ENABLED green badge means customers can see the product. DISABLED hides it.
2
Edit Basic Information
The first section when you open a product. Update core details here.
Basic Information — Product Name, SKU, Price, Brand and Product Type.
Product Name
Shown on storefront and search results. Keep consistent with other products.
SKU
Internal product code. Don’t change unless instructed.
Default Price
Price including tax shown to customers.
Brand
Select from the dropdown — don’t add a new one without approval.
⚠️ Always click Save at the bottom after making changes. Navigating away loses edits.
3
Edit Categories and Description
Scroll down past Basic Information to find Categories and Description.
Categories (top) — tick/untick to add/remove from collection pages. Description (bottom).
Categories
Tick to add the product to a collection page. You can tick multiple categories.
Description
Rich text shown on the product detail page. Keep tone consistent.
💡 If a product isn’t showing on a collection page, check the correct category is ticked here.
4
Manage Product Images
Scroll to the Images section. The THUMBNAIL badge marks the main image shown in grids and search.
Images section — THUMBNAIL = main image. Click + to upload. Click Remove to delete.
Thumbnail
First image = thumbnail. Drag another image to the first position to change it.
Alt text
Fill in for every image. E.g. PA First Nations Guernsey front view.
💡 Best size: 800×800px or larger, JPG or PNG, under 1MB.
⚠️ Deleting an image is permanent. Save the file locally before removing.
5
Save your changes
Scroll to the bottom and click Save. Changes go live immediately — no separate publish step needed.
Scroll to bottom → click Save
⚠️ Product edits go live immediately on save. Double-check before saving.

Stage 1 — Prepare the file
📥
Download the template
Always start from the Port Store template. Column names must match exactly — don’t rename or add columns.
📥 Download Lightspeed Upload Template
📄
One row per variant
Each size gets its own row. Product name, category, prices, brand and supplier repeat on every row — only SKU, barcode and size change per row.
ℹ️
Products with no variants still get one row — leave variant_option_one_name and variant_option_one_value blank.
💾
Save as CSV UTF-8
Save using File → Save As → CSV UTF-8 (Comma delimited).
⚠️
Don’t use “CSV (MS-DOS)” — it breaks special characters on import.
✔️
Quick checks before you save
🔢 Barcode column formatted as Text — prevents 8.05E+12
📷 Every row has a unique sku_code_custom
💰 Prices are numbers only — no $ symbols
📝 Product names identical across all rows for the same product
📷 Tags semicolon-separated: 2026 Macron Range;2026 SDNR
Stage 2 — Column reference

Stage 3 — Run the import
⚠️
Test first. Run a small file of 5–10 products before your full upload.
💻
Navigate to the import tool
Products›Import / Export›Import Products
☑️
Select import type
Choose Add new products for a new range.
🚫
Don’t use “Update existing” for a new range — rows with no existing match are silently skipped.
📤
Upload CSV and confirm mapping
Click Choose File, select your CSV, then Next. Manually assign anything showing “Not mapped”.
▶️
Run the import
Click Import and don’t navigate away. Any skips above zero need investigating.
Troubleshooting
⚠️ Rows being skipped with no error
Usually a column mapping issue or wrong import type. Check headers match the template exactly and confirm you chose Add new products.
🔢 Barcodes show as scientific notation (8.05E+12)
The barcode column is formatted as a number. Select the column, format as Text, re-paste barcodes as values, then re-export the CSV.
📄 Duplicate products instead of variants
A variant row has a slightly different product name — even a trailing space causes Lightspeed to create a new product. Use Excel find-replace to standardise.
📁 Category not found
Category name doesn’t exactly match Lightspeed. Pull the exact name from Products → Categories in Back Office.
💰 Prices show as $0.00 after import
Price columns contain a $ symbol or comma. Remove with find-replace, re-export, then re-import using Update existing products.

From the product spreadsheet
Recommended

✓ Clean and consistently formatted
✓ Much faster for large ranges

From a Lightspeed export
Export from Lightspeed Back Office. Only use when you don’t have the original spreadsheet.
✓ Useful for products already in Lightspeed
✗ Lightspeed does not export barcodes
⚠️
For any range larger than a handful of products, use the product spreadsheet path wherever possible.

💬 Customer Service Procedures
AWDS Fulfilment · Online Orders · Internal Reference
📍 Address Issues ✈️ International Tracking 📦 Stock Issues ❌ Cancellations 🔍 Missing Orders
📍
Address Issues
Flagged by AWDS when a delivery address can’t be resolved
ℹ️
AWDS will contact you directly when they can’t deliver to an address — typically the suburb, city or postcode was entered incorrectly at checkout.
1
Google the address
Take the street number and name from the order and search Google Maps to confirm the correct suburb and postcode. Resolves most cases without contacting the customer.
2
If you can’t confirm — email the customer
Ask the customer to confirm their full delivery address including suburb and postcode.
📧 Suggested email
Hi [Name], We’re getting in touch regarding your recent Port Store order. Our fulfilment team has encountered an issue with the delivery address we have on file. Could you please confirm your full delivery address — including street, suburb and postcode — so we can get your order on its way? Thanks, Port Store Team
3
Update in BigCommerce and notify AWDS
Once confirmed, update the shipping address on the order in BigCommerce and pass the corrected details back to AWDS so they can proceed with dispatch.
✈️
